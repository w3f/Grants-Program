## Project Overview

GaiaSpeak Core is a decentralized, resilient communication and asset synchronization layer designed for off-grid operations[span_0](start_span)[span_0](end_span)[span_1](start_span)[span_1](end_span). The system integrates a 5-oracle consensus mechanism anchoring precious-metal tokens (GSG Gold and GSS Silver) with offline-first mesh networking[span_2](start_span)[span_2](end_span)[span_3](start_span)[span_3](end_span)[span_4](start_span)[span_4](end_span)[span_5](start_span)[span_5](end_span).

### Project Details
* *Core Protocol:* Implements 5-oracle consensus to verify physical metal reserves via Chainlink feeds (XAU/USD and XAG/USD)[span_6](start_span)[span_6](end_span)[span_7](start_span)[span_7](end_span).
* *Decentralized Settlement:* Enables p2p trading, micro-transfers, and content monetization (60/20/20 split) via GaiaSpeakNFT.sol using native GSG and GSS tokens[span_8](start_span)[span_8](end_span)[span_9](start_span)[span_9](end_span)[span_10](start_span)[span_10](end_span).
* *Off-Grid Mesh Integration:* Low-power wearable node architecture utilizing LoRa, BLE, and WiFi-Direct relays for emergency communications without central ISPs[span_11](start_span)[span_11](end_span)[span_12](start_span)[span_12](end_span).
